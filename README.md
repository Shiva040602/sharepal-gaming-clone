# SharePal Gaming Gadgets — Frontend Assignment

A responsive frontend recreation of the SharePal Bangalore gaming-gadgets listing experience.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Supplied `product-list.json` data converted into `products.js`
- SharePal product image URLs are used as remote image sources

## Run locally
No build step is required.

### Option 1
Open `index.html` in a browser.

### Option 2 (recommended)
Use VS Code Live Server or run:
```bash
python -m http.server 5500
```
Then open:
`http://localhost:5500`

## Included interactions
- Product category filtering
- Product search
- Sorting
- Wishlist buttons
- Rental shortlist/cart counter
- Rental date modal with validation
- FAQ accordion
- Review carousel
- Responsive mobile layout
- Hover transitions and image effects

## GitHub
1. Create a new GitHub repository, e.g. `sharepal-gaming-gadgets`.
2. Upload all files from this folder.
3. Commit and push.

## Deploy with GitHub Pages
1. Open the repository on GitHub.
2. Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Save.
6. GitHub will provide the live URL.

## Deploy with Netlify
Drag the project folder into Netlify's deploy area, or connect the GitHub repository.
